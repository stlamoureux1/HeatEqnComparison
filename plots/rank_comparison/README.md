# Performance Comparison by MPS Rank

This folder contains a plots for the approximate solutions of an MPS solver of varying maximal rank for source and solution terms, using finite differences + forward Euler. 

The problem is given by 
```
x in [0,1]
t in [0,0.5]
2^7 interior x grid points
source term sine coefficients = [9.869604401089358, 39.47841760435743, 88.82643960980423, 157.91367041742973, 246.74011002723395, 355.3057584392169, 483.61061565337855, 631.6546816697189, 799.437956488238, 986.9604401089358]
```

The source term sine series coefficients were generated by calling 
```
fCoeff = [(n * pi)^2 for n in 1:10]
```
in order to force a higher-rank solution.

Files are named by rank. For example, `plt_r1` shows the approximate solution for rank 1 approximation of *both* the solution and source term.
